# AdSense 콘텐츠 보완 기록 — 2026-09-20

## 확인한 문제

- AdSense의 algogayo.com 사이트 상세에서 ‘가치가 별로 없는 콘텐츠’로 준비되지 않음 상태를 확인했다. 소유권과 ads.txt는 확인된 상태였다.
- 운영 도메인은 main의 `be1a066`(기존 8편)을 제공하고 있었다. 원격 저장소의 20편 개편본은 미리보기 배포에만 존재했다.
- Google은 문제가 된 개별 문장이나 URL을 제시하지 않았다. 아래 항목은 코드와 운영 화면을 검토해 정한 개선 사항이며 Google의 내부 판정 원인을 확정한 설명이 아니다.

## 반영한 개선

- 기존 20편 개편 브랜치를 기반으로 모든 글을 검토했다. 원래 운영 중인 8편에는 적용 조건, 계산 과정, 실패 시 대응, 공식 확인 경로를 보강했다.
- 추가 12편의 첫 운영 게시일은 실제 배포 예정일인 2026-09-20으로 표시했다. 설명용 사례를 실제 체험이나 조사 결과처럼 제시하는 표현을 수정했다.
- 상품의 실제 사용량을 반영하는 단위 가격 계산기와 위약금·할인 감소를 포함하는 고정비 전환 계산기를 추가했다.
- 20편 각각에 체크 가능한 확인 목록과 주제별 빈 기록표(.txt)를 제공한다. 입력값과 체크 상태는 서버 전송·지속 저장하지 않는다.
- 사진 동기화와 백업, 구독 취소와 계정 삭제, 의심 문자 클릭과 실제 피해 발생을 구분했다. 되돌릴 수 없는 삭제나 불필요한 시험을 권하는 문구를 수정했다.
- 운영자 ‘알고가요’, 공개 문의 주소 `contact@algogayo.com`, 편집 원칙, AI 보조 작성 및 일러스트레이션 사용 범위를 안내했다.
- 심사 중 광고 로더를 제거했다. 소유권 확인 메타 태그와 ads.txt는 유지한다. 광고 로더 제거만으로 저가치 콘텐츠 문제가 해결된다는 의미는 아니다.

## 검증

- 계산 함수 테스트: 실제 사용량, 0원 상품, 잘못된 입력, 전환 비용 회수, 비교 기간 내 손실.
- ESLint, TypeScript 검사, Next.js 프로덕션 빌드 통과.
- 실제 브라우저에서 두 계산기의 입력 변경과 결과, 체크리스트 상태, 모바일 메뉴를 확인했다.
- 모바일 폭 390px에서 계산기와 글의 가로 넘침이 없음을 확인했다.
- 로컬 프로덕션 서버에서 사이트맵 29개 URL, 글 20편, 연결된 리소스 54개, RSS 글 20편, ads.txt, 404/noindex를 검사했고 오류가 없었다. 소유권 메타 태그는 모든 페이지에서 유지되고 광고 로더는 실행되지 않는다.
- 배포 후 검증과 재검토 요청 결과는 아래 운영 기록에 추가한다.

## Google 공식 기준

- [사이트에 고유 콘텐츠와 좋은 사용자 환경 제공](https://support.google.com/adsense/answer/7299563?hl=ko)
- [사이트를 광고 게재할 준비가 되도록 수정](https://support.google.com/adsense/answer/12176698?hl=ko)
- [게시자 콘텐츠가 없거나 가치가 낮은 화면](https://support.google.com/publisherpolicies/answer/11112688?hl=ko)

글 수나 글자 수만으로 승인을 보장하는 기준을 적용하지 않았다. 최종 승인 여부는 Google의 재검토 결과로 확인해야 한다.

## 운영 기록

배포와 AdSense 재검토 요청은 아직 완료 여부를 기록하지 않았다.
